# Learning Plan Generator

Create comprehensive, personalized learning plans based on your goals, current knowledge level, and available time.

## How to Use

```
/learning-plan <goal_description> [--level beginner|intermediate|advanced] [--hours-per-week <hours>]
```

## Plan Structure

Every generated learning plan includes:

### 1. Goal Analysis
- Understanding of the learning objective
- Prerequisites assessment
- Recommended starting level

### 2. Learning Path
- Phase 1: Foundations
- Phase 2: Core Concepts
- Phase 3: Advanced Topics
- Phase 4: Practice & Application

### 3. Weekly Schedule
- Recommended time allocation
- Topic breakdown per week
- Milestone checkpoints

### 4. Resource Recommendations
- Courses (free and paid)
- Books and articles
- Video tutorials
- Practice exercises
- Communities and forums

### 5. Assessment Methods
- Quizzes and tests
- Projects to build
- Practical exercises
- Self-assessment criteria

### 6. Review Schedule
- Spaced repetition intervals
- Recommended review points
- Knowledge retention strategies

## Example Output

```
Learning Plan: Mastering Machine Learning

Phase 1: Mathematics Foundations (Weeks 1-4)
- Linear Algebra
- Calculus
- Probability & Statistics

Phase 2: Core ML Concepts (Weeks 5-10)
- Supervised Learning
- Unsupervised Learning
- Model Evaluation

Phase 3: Advanced Topics (Weeks 11-16)
- Deep Learning
- Neural Networks
- Model Optimization

Phase 4: Practical Application (Weeks 17-20)
- Capstone Project
- Kaggle Competitions
- Portfolio Building
```

## Tips for Effective Planning

1. **Be realistic**: Consider your current commitments
2. **Start small**: Begin with achievable milestones
3. **Stay flexible**: Adjust the plan as you learn
4. **Include practice**: Theory alone is not enough
5. **Track progress**: Regularly review your advancement

## Special Features

- **Adaptive Planning**: Adjusts based on your progress
- **Resource Diversity**: Provides multiple learning sources
- **Community Recommendations**: Suggests forums and groups
- **Project-Based Learning**: Includes practical projects
- **Spaced Repetition**: Optimizes review intervals
